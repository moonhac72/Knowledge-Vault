# 사례_013 — 종합 현장 출동 보고: 강풍일 다종 조류 및 동물 대응 전술

## IF-THEN 판단 로직

IF 풍속 강함(12m/s 이상) + 공포탄 사용 필요 상황
THEN 공포탄 사용 자제, 엽총(실탄)으로 전환
WHY 강풍 시 공포탄 불발로 인한 화재 발생 우려 큼

IF 일몰 18:40분 전후 기러기 무리 동→서 또는 서→동 이동 관찰
THEN 1·2·3·4 활주로 횡단 지점 집중 감시 + 엽총 준비
WHY 기러기는 일몰에 맞춰 휴식장소로 이동하며, 동서 이동 시 모든 활주로 이착륙 지점을 가로질러 횡단하는 패턴이 반복됨

IF 강풍으로 기러기 이동이 분산되어 방향 예측 어려움
THEN 기러기 이동 방향 예측 후 무리 후방을 향해 엽총 발사
WHY 강풍 시 기러기가 분산되므로 선두가 아닌 후속 무리를 자극해야 신속한 이탈 유도 가능

IF 일몰 이후 배수로 조류(오리류) 퇴치 작업
THEN 33R 또는 15L(착륙 위주) 반대편 활주로 방향으로 이동 경로 유도
WHY 33L·15R는 이륙 위주, 33R·15L는 착륙 위주 운영이므로 랜딩 항공기 진입 경로에서 최대한 이격시켜야 함

IF 야간 배수로 조류 퇴치 시 이탈 방향 결정
THEN 바람 방향(이날 남→북) 확인 후 북측 바다 방향으로 유도
WHY 조류는 맞바람 방향으로 이탈하는 경향이 있으므로 풍향을 이용해 안전 방향으로 유도

IF 기러기 무리가 야간·조간에 15·16 지역 녹지대에 반복 출현
THEN 해당 구역 순찰 빈도 강화 + 일지 데이터 기반 출현 시간 사전 파악
WHY 기러기는 북단(15·16 지역) 녹지대 상주 습성이 확인된 상습 출현 지역임

IF 일출 후 기러기 무리 이동(아침 먹이 비행) 시간대
THEN 일출 직후부터 08:30~09:30 집중 감시
WHY 해가 뜨면 먹이터(논·밭·습지)로 이동하는 아침 먹이 비행 발생, 이후 08:30~09:30에 휴식지(Roosting Site)로 복귀하는 이중 이동 패턴 있음

IF 야간·조간 배수로 고인물에서 오리류 점검 시
THEN 열화상카메라 + 랜턴 병용, 배수로 말단부 우선 점검
WHY 오리는 바람막이(Thermal Refuge)와 포식자 회피를 위해 배수로를 선호하며, 활주로 개방지보다 체감온도가 높아 집중됨

IF 왜가리가 배수로 주변에서 서성이는 것 발견
THEN 접근 전 충분한 거리에서 퇴치 시작
WHY 왜가리는 경계심이 강해 사람·차량 접근 전 먼저 날아가지만, 항공기 소음에 둔감해 활주로 인근 배수로에서 자주 관찰됨 — 포획 시 단독 1개체(수컷 기준 1.7kg)

IF 까치 반복 출현 및 동일 퇴치 방법 효과 감소 확인
THEN 퇴치 방법 즉시 변경·다양화
WHY 까치는 지능이 높아 학습 효과가 빠르며 동일 퇴치 반복 시 내성 형성 — 기록 후 패턴 변경 시기 관리 필요

IF 터미널 계류장 주변 비둘기 집중 출현
THEN 음식물 쓰레기 등 먹이원 제거 환경 관리 요청
WHY 비둘기는 먹이원이 풍부한 터미널 계류장 선호, 건물 구조물 둥지로 완전 퇴치 어려우므로 환경 관리가 근본 대책

## 위협 우선순위

- 1순위: 기러기 무리의 활주로 횡단(일몰 18:40 전후, 동→서 또는 서→동) — 집단 이동으로 다수 개체가 이착륙 지점 가로질러 대형 충돌 위험
- 2순위: 쇠오리 야간 배수로 은신 후 수직 이륙 — 야간·새벽 시간대 엔진 흡입 높이와 중첩, 열화상카메라 없이 식별 불가
- 3순위: 황조롱이·말똥가리 호버링 — 지면 응시 중 항공기 접근 인지 불가, 착륙대 초지 상공 집중

## 종별 핵심 특성 요약

### 기러기
- 주간: 논·하천 섭식 → 일몰(18:40) 휴식지 이동
- 야간·조간: 북단 15·16 지역 녹지대 상습 상주
- 아침: 일출 직후 먹이터 이동 → 08:30~09:30 휴식지 복귀
- 강풍 시: 이동 분산 → 후속 무리 향해 엽총 발사로 이탈 자극

### 쇠오리
- 주간: 공항 외곽 저수지·갯벌 은신(배수로에서 거의 미관찰)
- 야간: 배수로 먹이(수초 씨앗·곤충유충) 활동 + 겨울 부동수 집결
- 위협: 수직 이륙 습성 — 항공기 엔진 높이와 중첩
- 식별: "프릿-프릿" 경계음, 열화상카메라로 조기 탐지

### 왜가리
- 단독 생활, 경계심 강함(접근 전 선제 비행)
- 항공기 소음 둔감 → 활주로 인근 배수로 상주 가능
- 포획 개체: 수컷 1.7kg

### 황조롱이
- 착륙대 초지 상공 호버링(Hovering)
- 설치류 밀도 높은 활주로 주변 초지가 유인 요인
- 호버링 중 시선 하향 — 항공기 미인지 위험

### 종다리
- 개방 초지 무리 지어 지면 먹이활동
- 놀라면 수직 상승 — 이착륙 항공기 위협

### 고라니
- 착륙대 수풀 은신, 차량 소리에 갑작스럽게 뛰쳐나옴
- 청각 예민 — 차량 접근 소리로 행동 유발
- 포획: 암컷 1개체

### 비둘기
- 터미널 계류장 주변 먹이원(음식물 쓰레기) 집중
- 구조물 둥지 서식 → 완전 퇴치 불가, 환경 관리 병행 필수

### 까치
- 학습 능력 높음, 동일 퇴치 방법 반복 시 내성 형성
- 퇴치 방법 다양화 및 변경 주기 관리 필수

### 흰뺨검둥오리
- 텃새화된 개체 많아 연중 관찰
- 배수로 고인물 야간 은신

---

## 장비·전술 운용 원칙

- 강풍(12m/s 이상) 시: 공포탄 자제 → 엽총(7호반) 사용
- 야간 관측: 열화상카메라 + 랜턴 병용
- 퇴치 이탈 방향: 풍향·착륙 활주로 방향 사전 확인 후 안전 방향으로 유도
- 활주로 운용 패턴 사전 인지: 33L·15R(이륙 위주) / 33R·15L(착륙 위주)
