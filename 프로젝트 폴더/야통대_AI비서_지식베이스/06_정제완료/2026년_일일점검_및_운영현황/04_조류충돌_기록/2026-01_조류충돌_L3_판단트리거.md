> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)

> **원본 데이터**: [[2026-01_조류충돌_L1_기록]]

## 사용 방법 (현장 배포용)

**항공기 조류충돌 신고를 받았는데 뭘 해야 해?**
1. 신고자, 활주로, 시간대, 충돌 부위를 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행

## 트리거 A — 신고 접수 후 현장 출동 기준

---

### A-01. 정비사/기장 신고 충돌 → 즉시 출동 🔴

```
IF  신고자가 정비사 또는 기장이다
AND 충돌 부위가 엔진 또는 핵심 구조물이다
AND 신고 시각이 명확하다
THEN 즉시 야통대 차량 출동
     → 목표 현장 도착 시간: 신고 후 10분 이내
     → 조직·깃털·잔해 사진 촬영 + 수거
     → 엔진 충돌인 경우 DNA 의뢰 검토 필수
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-002]] 참고 (신고6분 도착)
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] 참고 (신고7분 도착)
```

**근거 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-002]] (아시아나, 17:54 신고 → 18:00 도착 ✓)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] (대한항공, 07:08 신고 → 07:15 도착 ✓)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-006]] (에어부산, 07:20 신고 → 출동)

**성과**: 신고한 3건 모두 **현장 도착 기록 완벽**

**WHY**: 정비사 신고는 **이미 충돌 증거(조직)를 확보한 상태**. 신속한 출동으로 DNA 의뢰까지 이어져야 충돌 조류 종 확인 가능.

---

### A-02. 기장 공중 충돌(300ft↑) → 현장 출동 여부 재검토 🟡

```
IF  신고자가 항공기 기장이다
AND 충돌 고도가 300ft 이상이다
THEN 지상 수거 가능성 평가
     → 300ft 이상: 지상 잔해 가능성 낮음
     → 다만 활주로 포장면 주변 긴급 수색 실시
     → 충돌 시각·활주로·기장 진술 별도 기록
     → 향후 공중 충돌 추적 데이터로 활용
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-001]] 참고 (300ft, 미수거)
```

**근거 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-001]] (제주항공, 300ft 접근 중 충돌)

**현장 판단**:
- 300ft 이상 충돌 → 지상 잔해 없을 가능성 높음
- 하지만 일부 조직이 활주로 포장면에 흩어질 수 있으므로 긴급 수색 필수
- 수거물이 없어도 **"공중 충돌 기록"**으로서 별도 데이터 수집 필요

**WHY**: 공중 충돌 건이 야통대 기록에서 누락되면, 실제 공항 위협이 과소평가됨.

## 트리거 B — 활주로별 집중 순찰 기준

---

### B-01. 33R 활주로 야간 17:00~19:00 집중 퇴치 🚨

```
IF  시간대가 17:00~19:00 (야간)이다
AND 사용 활주로가 33R이다
THEN 33R 접근 경로 조류 집중 퇴치 = 우선순위 최고
     → 공포탄 + 폭죽 동시 운용 검토
     → 이 시간대 33R 사용 항공편 사전 공지
     → 강풍 조건 시 추가 경계 강화
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-001]] + [[2026-01_조류충돌_L1_기록#CASE-2026-01-004]] 참고
```

**근거 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-001]] (17:20, 33R, 날개 충돌)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-004]] (18:55, 33R, 엔진 충돌)
- **동일 활주로·야간 시간대 2건 반복**

**현장 판단**:
- 33R은 이달 6건 중 3건이 발생한 활주로
- 야간 시간대(17:00~19:00)에 반복 충돌 발생
- 패턴: 일몰 후 활주로 포장면 주변 조류 활동 집중

**WHY**: 33R 접근 경로상 저공 비행 조류 밀집 구역 존재 가능성. 이 시간대는 **예측 가능하고 예방 가능한 위협**.

---

### B-02. 일출 전후 06:00~08:00 전 활주로 집중 순찰 🟡

```
IF  시간대가 06:00~08:00 (일출 전후)이다
THEN 모든 활주로 동시 집중 순찰 실시
     → 33R(건3), 34L(건6), 15R(건5) 모두에서 발생
     → 공포탄 사전 준비 + 순찰차 다중 배치
     → 특히 대형 도착편(B787, A330) 우선 경계
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] 참고 (일출전후 33R)
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-006]] 참고 (일출전후 34L)
```

**근거 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] (07:08, 33R, 엔진 충돌)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-006]] (07:20, 34L, 엔진 충돌)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-005]] (05:13 도착, 15R)

**현장 판단**:
- 일출 직후는 조류의 먹이 활동이 가장 활발한 시간
- 이달 주간 충돌 4건 중 3건이 이 시간대 발생
- 활주로 전역에서 발생 → 포장면 전체 모니터링 필요

**WHY**: 사례_009 "베테랑 현장판단력"의 **골든타임**과 정확히 일치. 이 시간대는 공항 안전의 최대 위협 시간.

## 트리거 C — 신고 기준 및 증거 보존

---

### C-01. 충돌 후 세척 전 야통대 신고 원칙 🔴

```
IF  정비팀이 항공기 충돌 흔적을 발견했다
THEN 아래 순서를 반드시 준수한다

1. 세척 금지 (증거 소실 방지)
2. 야통대 신고 (즉시)
3. 충돌 부위 사진 촬영 (세척 전)
4. 조직·깃털 수거 (야통대 지도)
5. 기장 진술 기록 (충돌 시각·위치·고도)

→ DNA 의뢰 가능 상태 유지
→ [[2026-01_조류충돌_L1_기록#CASE-2026-01-005]] 반면교사 참고
```

**반면교사 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-005]] (티웨이항공, 세척후신고 → 증거 소실 → DNA의뢰 불가)

**현장 판단**:
- 세척이 한 번 완료되면 조직 샘플 영구 소실
- 조직 없으면 DNA 분석 불가능
- 결과: 충돌 조류 종 영구 미확인

**WHY**: 충돌 조류 종을 알아야만 향후 같은 종의 추가 충돌을 예방할 수 있음. 세척 전 신고는 **공항 안전 데이터의 기초**.

---

### C-02. 엔진 충돌 = 자동 DNA 의뢰 규칙 🔴

```
IF  충돌 부위가 엔진이다
AND 조직 또는 깃털을 수거했다
THEN 자동으로 DNA 의뢰 진행
     → [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] 모범 사례 (DNA의뢰 실시)
     → 대조: [[2026-01_조류충돌_L1_기록#CASE-2026-01-002]] (조직 수거했으나 미의뢰 ❌)
```

**근거 사건**:
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-003]] (엔진 충돌 → DNA 의뢰 ✓ 유일한 성공 사례)
- [[2026-01_조류충돌_L1_기록#CASE-2026-01-002]] (엔진 충돌 → DNA 미의뢰 ❌)

**현재 문제**:
- 엔진 충돌 4건 중 DNA 의뢰는 1건만 실시
- 조직을 수거했으면 의뢰해야 하는데 절차 미실시 사례 있음

**WHY**: 엔진 충돌은 다중 충돌 또는 대형 사고로 이어질 수 있는 최고 위협. 반드시 조류 종을 파악해야 함.

---

### C-03. 야통대 미신고 충돌 건 사후 추적 🟡

```
IF  조류충돌 관리 시스템에 기록이 있으나
    야통대 출동 기록이 없다
THEN 원인을 아래 순서대로 파악한다

1. 공중 충돌(300ft↑)인가? → 지상 수거 불가
   [[2026-01_조류충돌_L1_기록#CASE-2026-01-001]]

2. 정비팀이 세척후신고했는가? → 증거 소실
   [[2026-01_조류충돌_L1_기록#CASE-2026-01-005]]

3. 정비팀이 신고를 안 했는가? → 신고 기준 미숙지
   [[2026-01_조류충돌_L1_기록#CASE-2026-01-004]]

→ 이달 미인지 3건이 바로 이 3가지 원인
```

**현장 판단**:
- 야통대가 인지하지 못한 충돌이 전체의 50% 존재
- 원인이 각각 다르므로 대응도 차별화 필요

**WHY**: 미인지 충돌 건이 누적되면 실제 공항 위협이 과소평가됨. 정기적 교차검증으로 누락 건을 식별하고 개선해야 함.

## 트리거 D — 월간 통합 평가

---

### D-01. 1월 조류충돌 종합 평가

```
IF  1월 조류충돌 데이터 분석이 완료되었다
THEN 다음을 종합 평가한다

【발견 사항】
- 전체 6건 중 야통대 미인지 3건(50%) → 구조적 문제 존재
- 33R 활주로 3건 집중(50%) → 해당 경로 조류 밀집 확인
- 야간+일출전후 6건(100%) → 예측 가능한 위협 시간대
- 엔진 충돌 4건(67%) → DNA 의뢰 필수 건 많음
- DNA 의뢰 1건/필요 건 4건 → 의뢰율 25% (낮음)

【2월 선제 대응】
1. 정비팀 신고 기준 재교육
   → 엔진 충돌 = 반드시 야통대 신고
2. 세척 전 신고 원칙 강제화
   → 항공사 공문 발송
3. 33R 야간 17:00~19:00 집중 퇴치
4. 일출 전후 전 활주로 동시 경계
5. 시스템 vs 출동 기록 월간 교차검증 루틴 수립
```
