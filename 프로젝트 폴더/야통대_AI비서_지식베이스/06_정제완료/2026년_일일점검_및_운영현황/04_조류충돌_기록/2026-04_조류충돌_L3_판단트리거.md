## 사용 방법 (현장 배포용)

**충돌 신고가 들어왔을 때, 즉시 무엇을 판단해야 하는가?**
1. 고도, 활주로, 엔진 번호를 확인
2. 아래 트리거 A/B/C 중 일치하는 항목 확인
3. THEN → 즉시 행동 지침 실행

---

## 트리거 A — 고고도 및 항로 위협 대응

---

### A-01. 3,000ft 이상 고고도 충돌 신고 시 🚨 (최고 경보)

```
IF  기장이 3,000ft 이상에서 충돌을 보고했다 (PIREP)
THEN 즉시 해당 활주로 이륙/착륙 경로상의 'Staging Area' 예찰
     → 활주로 외곽 5km 반경 내 맹금류 선회 확인
     → 상승기류 발생 구역(공장 지대 등) 집중 타격
     → [[2026-04_L1_신고기록#CASE-2026-04-013]] (7,000ft) 근거 적용
```

---

## 트리거 B — 엔진 및 기체 핵심 부위 보호

---

### B-01. 외측 엔진(No. 4) 충돌 신고 시 🔴

```
IF  충돌 부위가 4번 엔진이다
THEN 해당 항공기의 접근 경로(Final Approach) 상의 특정 지형물 재점검
     → 조류가 엔진 흡입구 높이로 비상하는 '환경적 유인 요소' 수색
     → DNA 분석 의뢰 우선순위 '긴급'으로 격상
```

---

## 트리거 C — 계절적 특수종 대응 (칼새/제비)

---

### C-01. 칼새/제비 등 고속종 저고도 출현 시 🔴

```
IF  윈드실드 또는 레이돔 충돌이 보고됐다
AND 고도가 500ft 이하 저고도다
THEN 고속 활공종(칼새 등)의 '블라인드 침투'로 판단
     → 음향 퇴치기 주파수 변동 모드 가동 (회피 방지)
     → 총기 탄막 전술 실시
```
