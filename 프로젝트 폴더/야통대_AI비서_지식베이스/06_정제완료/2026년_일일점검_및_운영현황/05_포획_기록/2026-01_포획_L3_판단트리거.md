## 사용 방법 (현장 배포용)

**포획 순찰 중 조류를 발견했는데 우선순위가 뭐야?**
1. 발견한 조류 종과 위치를 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행

## 트리거 A — 3R/W 배수로 집중 순찰

---

### A-01. 3R/W 배수로 수조류 발견 → 우선순위 최고 🚨

```
IF  발견 위치가 3R/W 배수로(남측 또는 북측)다
AND 조류 종이 수조류(오리류, 쇠오리)다
THEN 즉시 아래를 실행한다

1. 단독 개체 → 즉시 포획/퇴치
2. 복수 개체 → 당일 추가 순찰 횟수 증가
3. 동일 구역 3일 이상 연속 발견 → 먹이원 집중 구역으로 확정
   → 사례_008 연동: 와이어 설치 요청

근거: [[2026-01_포획_L1_기록#CASE-2026-01-002]] (01-03)
     [[2026-01_포획_L1_기록#CASE-2026-01-013]] (01-22~27 쇠오리 6일)
```

**현장 판단**:
- 3R/W 배수로 = 전체 포획 개체의 33% 집중 구역
- 이 구역이 근절되지 않으면 계속 새로운 개체 유입
- 물리적 차단(와이어 설치) 필수

**WHY**: 배수로 수면은 조류의 먹이원 + 휴식처. 이 구역을 통제하지 않으면 포획의 효과가 일시적.

---

### A-02. 쇠오리 신규 개체 발견 → 선두 효과 차단 🔴

```
IF  쇠오리가 3R/W 배수로에서 발견된다
AND 최근 3일 내 같은 위치에서 포획된 기록이 있다
THEN 군집 형성 초기 단계로 판단하고 전수 포획 원칙 적용

패턴 분석 ([[2026-01_포획_L2_패턴분석#쇠오리-신규-출현]]):
- 01-22: 1개체 → 01-25: 1개체 → 01-26: 3개체 폭증
- 선두 개체 1마리 = 동료 유인 신호
- 3일 내 재발견 = 군집화 신호

```

**현장 판단**:
- 쇠오리 처음 발견(01-22) → 3일 후 1마리 추가 → 1일 후 3마리 폭증
- 이것이 전형적인 선두 효과 패턴
- 선두 개체를 빨리 포획하지 않으면 다음 날 급증

**WHY**: 조류는 선두 개체의 행동을 학습하고 따라간다. 선두 신호를 빨리 차단해야 군집화 방지 가능.

## 트리거 B — 대형 백로류(왜가리·대백로·중대백로) 우선순위

---

### B-01. 대형 백로류 배수로 진입 → 4호탄 타격 🔴

```
IF  왜가리 또는 대백로·중대백로가 배수로 수면에 진입한다
THEN 4호탄(위심 사격) 타격 원칙 적용

위협 등급 판단:
- 활주로 배수로 인접 → 위협 '높음' / 즉시 4호탄
- 주기장 배수로 → 위협 '중간' / 4호탄 후 추가 순찰
- 초소 외곽 → 위협 '낮음' / 퇴치 후 모니터링

1월 대형 백로류 포획 11개 분포:
- 왜가리 4개 (배수로/녹지대 혼합)
- 대백로 3개 (배수로 중심)
- 중대백로 4개 (배수로/유도로 중심)

근거: [[2026-01_포획_L1_기록#CASE-2026-01-001]] (01-02, 다종 동시)
     [[2026-01_포획_L1_기록#CASE-2026-01-004]] (A/S 15 배수로)
```

**현장 판단**:
- 대형 백로류 = 항공기 충돌 시 엔진 손상 위험
- 공포탄 부족, 4호탄 필수
- 사례_009: 왜가리가 수로 진입 전 "날개 반접기" 정지 비행 보이면 3~5초 후 수면 진입으로 판단

**WHY**: 대형종은 엔진 흡입 가능성이 높음. 강력한 퇴치 필수.

## 트리거 C — 주기장(851, 841) 까치 관리

---

### C-01. 851·841 주기장 까치 반복 포획 → 둥지 관리 연계 🟡

```
IF  851 또는 841 주기장 인근에서 까치가 포획된다
THEN 해당 주기장 조명탑을 사례_007 연동 둥지 점검 리스트에 추가

포획 이력:
- 01-12: 851, 841 동시 포획
- 01-22: 851 재포획 (10일 만에 재진입)
- 01-29: FG1 인근 까치

의미: 851·841이 까치 텃세 점유 구역임을 의미

→ 2월 말부터 사례_007 연동 둥지 사전 점검 시작
   기다렸다가 3월이 되면 둥지 다수 → 응급 대응
   2월 말에 미리 점검하면 선제 차단 가능
```

**현장 판단**:
- 같은 주기장에서 반복 포획 = 텃새 점유 구역
- 3월 산란기에 둥지 다발 설치 예상
- 2월 말 점검으로 선제 차단 가능

**WHY**: 까치는 귀소 본능이 강함. 전년도 똑같은 위치에 둥지를 트는 습성.

## 트리거 D — 강풍 + 고조 조합 집중 순찰

---

### D-01. 강풍(6m/s↑) + 고조(10물↑) 조합 → 전역 집중 🟡

```
IF  풍속 6m/s 이상 강풍이고
AND 조석 10물 이상 고조 구간이다
THEN 포획 강화 모드 개시

우선순위 순찰 구역:
1. 3R/W 배수로 (남·북 동시)
2. 2R/W 배수로 + 유도로
3. A/S 15 배수로
4. 4R/W 남측 배수로
5. 주기장 인근 녹지대

1월 강풍+고조 사례:
- 01-02: 강풍 6물 → 3종 동시 포획
- 01-06: 강풍 10물 → 대백로·까치
- 01-09: 강풍 13물 → 중대백로 2
- 01-11: 강풍 15물 → 다종
- 01-25: 강풍 14물 → 쇠오리
- 소계: 약 12개체 (36%)

강풍+고조 미충족: 나머지 21개체 (64%)
```

**현장 판단**:
- 강풍: 조류가 비행 회피 → 지표면/수면 근처 착지
- 고조: 배수로/녹지대 수면 확장 → 착지 구역 증가
- 조합: 포획 가능성 최고

**WHY**: 기상 조건이 포획 난이도를 결정함. 예측 가능한 유리 조건.

## 트리거 E — 포유류 침입 대응 (족제비 01-11)

---

### E-01. 포유류(족제비) 포획 → 울타리 점검 필수 🔴

```
IF  기동지역 녹지대에서 족제비가 포획된다
THEN 즉시 아래 순서로 조치한다

1. 포획 지점(145번 녹지대) 반경 100m 울타리 점검
2. 침입 경로 사진 기록 + 향후 보수 참고자료 작성
3. 추가 개체 유입 여부 모니터링
4. 족제비 굴(서식처) 흔적 확인
5. 인근 조류 사체 발생 추적 (포식 피해)

족제비 특징:
- 소형 포식성 포유류
- 조류 포식자 (조류 개체 감소 유인)
- 울타리 손상 신호 (추가 포유류 침입 가능)
- 고라니, 멧돼지 침입 전조

근거: [[2026-01_포획_L1_기록#CASE-2026-01-008]] (01-11, 145번 녹지대)
```

**현장 판단**:
- 족제비 1개 = 울타리 침입 경로 존재 증거
- 추가 개체 또는 더 큰 포유류 침입 가능성
- 즉시 펜스 점검 필수

**WHY**: 포유류가 들어올 수 있는 경로가 있으면 고라니·멧돼지도 진입 가능. 조기 차단 필수.

## 트리거 F — 소방분소 B 인근 다종 소형조류 관리

---

### F-01. 소방분소 B 인근 다종 포획 → 은신 구조물 점검 🟡

```
IF  소방분소 B 인근에서 3종 이상 서로 다른 조류가 포획된다
THEN 해당 구역의 은신처·먹이원 구조물 정밀 점검

1월 포획 이력:
- 01-08: 큰부리까마귀
- 01-18: 멧새 + 직박구리 근처
- 01-26: 직박구리

특징: 3회 포획, 모두 다른 종
→ 특정 종의 반복 유입 아닌 "다양한 소형조류 은신처" 기능 중

점검 항목:
- 건물 틈새 (은신처)
- 폐기물/음식물 (먹이원)
- 전기선/구조물 (정착지)
```

**현장 판단**:
- 소방분소 = 음식물 배출 가능 구역
- 건물 틈새 = 소형조류 은신처
- 다종 출현 = 구조적 환경 문제

**WHY**: 소형조류는 먹이와 은신처가 인접하면 정착. 환경 정비로 근본 차단 필요.
