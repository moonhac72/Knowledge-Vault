# 2026-04 포획 L3 판단트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-04_포획_L2_패턴분석]]
> **원본 데이터**: [[2026-04_포획_L1_기록]]
> **적용 범위**: 4월 데이터 기반 (표본 약 90개체)
> **신뢰도 단계**: ★★★★★ (최고)

---

## 사용 방법 (현장 배포용)

**포획 순찰 중 조류 군집이나 특이종을 발견하면?**
1. 종, 위치, 군집 규모를 확인
2. 아래 트리거 A/B/C 중 일치하는 항목 확인
3. THEN → 즉시 포획 전략 실행

---

## 트리거 A — 소형 군집종 (꼬마물떼새 등) 대응

---

### A-01. 소형종 3마리 이상 군집 발견 시 🚨 (집중 포획)

```
IF  꼬마물떼새·도요류가 3마리 이상 군집을 이루고 있다
AND 발견 위치가 배수로(16, 33, 34) 인근이다
THEN 경퇴(Scaring)보다 포획(Capture) 우선 적용
     → 선두 개체부터 순차적 생포
     → 24시간 내 동일 구역 재유입 여부 밀착 감시
     → [[2026-04_포획_L1_기록#CASE-2026-04-012]] (7마리 군집) 근거
```

---

## 트리거 B — 이동기 희귀종 및 대형종 보호

---

### B-01. 중부리도요 등 이동기 도요류 출현 시 🔴

```
IF  중부리도요·큰물떼새 등 이동종이 관찰된다
THEN 즉시 해당 녹지대 전수 포획 모드 가동
     → 이동 경색 구간(Bottleneck) 차단
     → 포획 후 즉시 원거리 방사 프로토콜 실행
```

---

## 트리거 C — 지상 조업 구역(GSE 도로) 보안

---

### C-01. GSE 도로 인근 기착 조류 발견 시 🔴

```
IF  제비·종다리·할미새류가 GSE 도로 포장면에 앉아 있다
THEN 차량 충돌(로드킬) 방지를 위한 즉시 생포 실시
     → 조업 차량 이동 경로 확보를 위해 최단 시간 내 조치
     → 사체 발생 시 즉시 수거하여 포식자(까마귀) 유인 차단
```

---

## 트리거 D — 최상위 포식자 통제

---

### D-01. 야생고양이 등 포유류 포식자 인지 시 🚨 (최고 경보)

```
IF  기동지역 내 야생고양이 또는 삵 등 포식자가 발견된다
THEN 48시간 내 포획망 집중 설치
     → 조류의 비정상적 이동(돌발 비상) 유발 요인 제거
     → [[2026-04_포획_L1_기록#CASE-2026-04-017]] 참고
```
