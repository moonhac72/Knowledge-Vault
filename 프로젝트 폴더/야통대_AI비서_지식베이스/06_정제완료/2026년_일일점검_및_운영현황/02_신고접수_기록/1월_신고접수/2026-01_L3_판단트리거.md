# 2026-01 L3 판단 트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-01_L2_패턴분석]]
> **원본 데이터**: [[2026-01_L1_신고기록]]
> **적용 범위**: 1월 데이터 기반 (표본 13건)
> **신뢰도 단계**: △ 표준 (2월·3월 데이터 추가 시 상향)

---

## 사용 방법 (현장 배포용)

**지금 이 상황인데 뭘 해야 해?**
1. 현재 상황의 기상·장소·시간을 먼저 확인
2. 아래 트리거 A/B/C/D 중 일치하는 것 찾기
3. THEN → 즉시 실행
4. WHY → 판단 근거 이해 (선택사항)

## 트리거 A — 기상조건 기반

---

### A-01. 강풍 + 수조류 사체 연속 발견 ⚠️

```
IF  풍속이 강풍(6~10m/s) 이상이다
AND 당일 수조류 사체 신고가 1건 이상 접수됐다
THEN 동일 기상 조건 내 추가 수조류 유입 가능성 = 높음
     → 유도로·주기장 수조류 사체 추가 발견 여부 즉시 집중 점검
     → 기상 변화 시까지 유도로 1시간마다 순찰 강화
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-003]] (06:00 물닭) + [[2026-01_L1_신고기록#CASE-2026-01-004]] (11:01 뿔논병아리)
- 동일 날짜(2026-01-02) / 동일 기상(맑음 + 강풍 6~10m/s)
- 수조류 2종 연속 발견 → 강풍이 수조류를 공항으로 밀어넣는 패턴 확인

**관련 L2 분석**: [[2026-01_L2_패턴분석#풍속별]]

---

### A-02. 눈/비 + 강풍 → 충돌 위험 격상 🔴

```
IF  날씨가 눈 또는 비다
AND 풍속이 강풍(6~10m/s) 이상이다
THEN 조류충돌 위험 = 경계 단계로 즉시 격상
     → 주기장 집중 점검 우선 시행
     → 기장·정비사 인지 여부 사전 확인 연락 실시
     → 조직·깃털 수거 시 DNA 분석 의뢰 즉시 시행
     → [[2026-01_L3_판단트리거#C-04]] 자동 트리거 활성화
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-008]] (눈/비 + 강풍 + 14물)
- **결과**: 정비 점검으로 격상된 **1월 유일한 사건**
- 1월 기상 최악 조건에서 충돌 발생 확인

**관련 L2 분석**: [[2026-01_L2_패턴분석#날씨별]]

---

### A-03. 가시거리 불량 + 강풍 + 저녁 → 활주로 말단 경계 🔴

```
IF  가시거리가 불량(1~3km) 이하다
AND 풍속이 강풍(6~10m/s) 이상이다
AND 시간대가 16:00~18:30이다
THEN 대형 철새 저녁 귀환 집결 패턴 = 최고 위험 상황
     → 활주로 말단(15L, 33R, 34L) 즉시 집중 경계 개시
     → [[2026-01_L3_판단트리거#C-02]] 트리거 함께 활성화
     → 인접 말단 구역 연쇄 점검 준비
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-010]] (강설 + 불량 + 17:05)
- [[2026-01_L1_신고기록#CASE-2026-01-011]] (강설 + 불량 + 17:13 → **300마리**) ⭐

**관련 L2 분석**: [[2026-01_L2_패턴분석#가시거리별]]

## 트리거 B — 조석(물때) 기반

---

### B-01. 대조기(13~15물) → 대형 철새 집결 경보 🚨

```
IF  조석이 13물 이상(대조기)이다
THEN 대형 철새(기러기류) 대규모 집결 가능성 = 높음
     → 1·2R/W 북측 + 활주로 말단 집중 순찰 즉시 실시
     → 4호탄 + 7호탄 비축량 사전 확인
     → 관제탑에 예비 경보 사전 공지
     → [[2026-01_L3_판단트리거#D-01]] 조건 부분 만족 — 다른 조건도 확인
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-007]] (13물, 08:12 출현)
- [[2026-01_L1_신고기록#CASE-2026-01-008]] (14물, 07:08 충돌-점검 격상)
- [[2026-01_L1_신고기록#CASE-2026-01-010]] (14물, 17:05 출현)
- [[2026-01_L1_신고기록#CASE-2026-01-011]] (15물, 17:13 **기러기 300마리**) ⭐ 최대 규모

**패턴**: 13물 이상 4건 중 3건이 **대규모 출현 또는 충돌 격상**. 15물은 **최고 위험 조석**.

**관련 L2 분석**: [[2026-01_L2_패턴분석#조석별-분포]]

### B-02. 중간조(6~9물) → 수조류 이동 활발 🟡

```
IF  조석이 6~9물(중간조)이다
THEN 수조류(오리류, 물닭 등) 이동 활발 상황 = 중간 수준
     → 유도로 포장면 수조류 사체 발견 가능성 높음
     → 발견 시 종 확인 후 국립생물자원관 DNA 분석 의뢰 즉시 시행
     → [[2026-01_L3_판단트리거#C-04]] 자동 트리거 활성화
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-003]] (6물, 물닭 사체)
- [[2026-01_L1_신고기록#CASE-2026-01-004]] (6물, 뿔논병아리 사체)
- [[2026-01_L1_신고기록#CASE-2026-01-005]] (6물, 활주로 출현)
- [[2026-01_L1_신고기록#CASE-2026-01-009]] (10물, 기러기 50마리)

**패턴**: 6~10물 구간에서 수조류 사체 3건 연속(06:00, 09:48, 11:01), 이어 저녁 대형 철새 50마리 출현.

**관련 L2 분석**: [[2026-01_L2_패턴분석#조석별-분포]]

### B-03. 소조기(1~5물) + 오전 시간 → 주기장 충돌 주의 🟡

```
IF  조석이 1~5물(소조기)이다
AND 시간대가 07:00~08:30이다
THEN 주기장 조류충돌 가능성 = 주의 단계
     → 주기장 순찰 우선 편성
     → 정비사 사전 연락 채널 확인
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-001]] (5물, 17:54 충돌)
- [[2026-01_L1_신고기록#CASE-2026-01-013]] (2물, 07:20 충돌) ← 소조기 + 오전

**해석**: 소조기에도 주기장 충돌이 발생한다. 기상 양호할 때도 방심 금지.

### C-01. 1·2R/W 북측(154번 복지대) — 반복 출현 위치 🔴

```
IF  신고 발생 위치가 1·2R/W 북측 또는 154번 복지대 인근이다
THEN 반복 출현 위치 패턴 = 확정
     → 현장 도착 즉시 복지대 방향 조류 집결 여부 확인
     → 대형 철새(기러기류) 출현 시 4호탄 + 7호탄 혼합 즉시 준비
     → 퇴치 후 동일 위치 30분 내 재출현 여부 추적 점검
     → [[2026-01_L2_패턴분석#반복-출현-위치-목록]] 참조
```

**근거 사건**:

- [[2026-01_L1_신고기록#CASE-2026-01-011]] (17:13, **기러기 300마리** 퇴치) ⭐ 최대
- [[2026-01_L1_신고기록#CASE-2026-01-012]] (05:45, 출현 의심)

**패턴**: 1월 중 동일 위치 **3건 반복 신고**. 154번 복지대가 기러기류의 고정 집결지.

**관련 L2 분석**: [[2026-01_L2_패턴분석#반복-출현-위치-목록]]

### C-02. 활주로 말단(15L, 33R, 34L) + 저녁 시간 → 집중 경계 🔴

```
IF  신고 발생 위치가 활주로 말단(15L / 33R / 34L)이다
AND 시간대가 16:30~18:30이다
THEN 대형 철새 저녁 귀환 집결 패턴 = 최고 경보
     → 현장 즉시 출동 (15분 이내)
     → 인접 말단 구역 연쇄 점검 실시 (같은 말단 2곳 동시 확인)
     → [[2026-01_L3_판단트리거#A-03]] 가시거리 불량 조건 함께 확인
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-009]] (17:20, 2R/W 33R, 기러기 50마리)
- [[2026-01_L1_신고기록#CASE-2026-01-010]] (17:05, 4R/W 34L, 출현)
- [[2026-01_L1_신고기록#CASE-2026-01-011]] (17:13, 1·2R/W 북측, **300마리**)
- [[2026-01_L1_신고기록#CASE-2026-01-014]] (17:19, 3·4R/W 출현)

**패턴**: 저녁 17:00~18:00 활주로 신고 **5건 모두 대형 철새 출현**. 이 시간대 활주로 말단은 기러기류의 저녁 귀환 시간.

**관련 L2 분석**: [[2026-01_L2_패턴분석#시간대별-분포]]

### C-03. 유도로·주기장 새벽 05:00~06:30 → 포유류 침입 점검 🟡

```
IF  신고 접수 시각이 새벽 05:00~06:30이다
AND 발생 위치가 유도로 또는 연락유도로 인근이다
THEN 포유류(고라니, 야생고양이 등) 침입 가능성 = 높음
     → 조류 점검과 동시에 유도로 양측 펜스 상태 육안 확인
     → 포유류 사체 발견 시 즉시 수거 후 침입 경로 추적 보고
     → FOD(이물질) 확인 후 즉각 제거 완료
```

**근거 사건**:
- [[2026-01_L1_신고기록#CASE-2026-01-006]] (05:47, G4 연락유도로, 고라니 사체)

**해석**: 새벽 안개 조건 + 유도로 근처 포유류 침입. 야간 펜스 손상 경로로 추정.

**관련 L2 분석**: [[2026-01_L2_패턴분석#포유류-침입]]

### C-04. 주기장 조류충돌 → DNA 분석 의뢰 자동 트리거 ⚠️ (중요)

```
IF  발생 장소가 주기장이다
AND 신고유형이 조류충돌이다
AND 조직·깃털이 수거됐다
THEN 국립생물자원관 DNA 분석 의뢰 즉시 시행 (자동)
     → 분석 결과 수령 후 보고서에 종명 대조 기록
     → 동일 주기장 반복 충돌 여부 과거 자료 대조
     → [[2026-01_L1_신고기록]] 해당 CASE 종명 업데이트
```

**근거 사건** (미실행):
- [[2026-01_L1_신고기록#CASE-2026-01-001]] (충돌, 조직 수거 → **의뢰 미기재**)
- [[2026-01_L1_신고기록#CASE-2026-01-008]] (충돌-점검 격상, 조직·깃털 수거 → **의뢰 미기재**)
- [[2026-01_L1_신고기록#CASE-2026-01-013]] (충돌-경미 → **의뢰 미기재**)

**문제**: **충돌 3건 모두 종 미확인 상태**. DNA 분석 의뢰 여부 추적 관리 시스템 필요.

**연계**: [[2026-01_L2_패턴분석#관련-조류종-확인-현황]] (62% 미확인 상태)

## 트리거 D — 복합 조건 (최고 위험 조합)

---

### D-01. 최고 위험 조합 → 즉시 경계 최고 단계 🚨🚨🚨

```
IF  조석이 13물 이상이다
AND 풍속이 강풍(6~10m/s) 이상이다
AND 시간대가 16:30~18:30이다
THEN 즉시 전 구역 경계를 최고 단계로 격상 (RED ALERT)
     → 1·2R/W 북측(154번 복지대) + 활주로 말단 동시 집중 순찰
     → 대형 철새 300마리 이상 집결 가능성으로 대비
     → 4호탄·7호탄·공포탄 비축 확인 → 충분하지 않으면 즉시 예비탄 준비
     → 관제탑 상황 보고 즉시 실시
     → 추가 인력 동원 준비 (기상 추이에 따라 현장 강화)
```

**근거 사건 (1월 최대 위험 사건)**:
- [[2026-01_L1_신고기록#CASE-2026-01-011]]
  - **날짜**: 2026-01-26
  - **기상**: 흐림 / 서풍 / 중풍 3~5m/s / **가시거리 불량(1~3km, 강설)**
  - **조석**: **15물 (1월 최고)**
  - **시간**: **17:13**
  - **결과**: **기러기 300여 마리 퇴치** (1월 최대 규모)

**참고**: CASE-011은 **A-03 + B-01 + C-01 + C-02** 조건을 모두 만족하는 복합 위험 상황이었음.

**D-01 발동 기준**:
- 3가지 조건 모두 동시 만족 시 = **100% 즉시 RED ALERT**
- 2가지 조건 만족 시 = YELLOW ALERT (경계 강화)
- 1가지 조건만 만족 시 = 해당 단일 트리거 적용

**관련 L2 분석**: [[2026-01_L2_패턴분석#월간-핵심-이슈-요약]]
