# 2026-03 L3 판단 트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-03_L2_패턴분석]]
> **원본 데이터**: [[2026-03_L1_신고기록]]
> **적용 범위**: 3월 데이터 기반 (표본 5건) + 1·2월 누적 15건
> **신뢰도 단계**: ▲ 표준 (Q1 누적 데이터 기반, 신뢰도 상향)

---

## 사용 방법 (현장 배포용)

**지금 이 상황인데 뭘 해야 해?**
1. 현재 상황의 장소·종·시간을 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행
4. WHY → 판단 근거 이해 (선택사항)

## 트리거 A — 소형종 활주로 기착 기반

---

### A-01. 활주로 중앙 종다리/물떼새 군집 🚨 (최고 경보)

```
IF  신고 위치가 활주로 포장면(중앙부)이다
AND 신고 종이 종다리 또는 물떼새류다
AND 개체 수가 3마리 이상이다
THEN FOD(이물질) 및 난류 휘말림 위험 = 최고 수준
     → 공포탄 초고밀도 사격 (10발 이상 연쇄 발사)
     → 개체 완전 이탈 확인
     → 활주로 포장면을 '위험 구역'으로 인식시키기
     → 사격 후 즉각 FOD 점검 실시
     → [[2026-03_L1_신고기록#CASE-2026-03-001]] 참고 (10마리 성공 사례)
```

**근거 사건**:
- [[2026-03_L1_신고기록#CASE-2026-03-001]] (종다리 10마리, 활주로 중앙, 공포탄 10발)

**왜 이게 위험한가**:
- 종다리는 지표 곤충 포식. 지열로 인한 곤충 유출에 반응하여 활주로에 기착
- 항공기 이착륙 시 난류에 휘말려 엔진 흡입 가능
- 소형종이지만 **다중 기착 패턴** 보임

**3월 신규 패턴**: 1·2월에는 없던 **활주로 중앙 기착** 신규 등장. 지열 상승 단계의 봄철 특화 위험.

---

### A-02. 주기장(원격주기장) 소형종 침입 🔴

```
IF  신고 위치가 원격 주기장 또는 정비 시설이다
AND 신고 종이 꼬마물떼새 또는 소형종이다
AND 개체 수가 3마리 이상이다
THEN 항공기 엔진 열기 이용 체온 유지 추정 = 주의
     → 도보 경퇴를 통한 강제 분산
     → 주기장 하부 및 인근 은신처 점검
     → 시설물 하부에 조류 접근 방지 도구(네팅 등) 설치 고려
     → [[2026-03_L1_신고기록#CASE-2026-03-003]] 참고 (꼬마물떼새 주기장 침입 사례)
```

**근거 사건**:
- [[2026-03_L1_신고기록#CASE-2026-03-003]] (꼬마물떼새 3마리, 원격 주기장)

**대응 포인트**: 주기장은 항공기 주기 위치. 조류가 엔진 열기를 이용하여 번식 준비 가능성 있음.

## 트리거 B — 대형 수변종 진입 기반

---

### B-01. 중백로/왜가리 유도로/활주로 주변 진입 🔴

```
IF  신고 종이 중백로 또는 왜가리다
AND 신고 위치가 유도로·배수로·활주로 주변이다
AND 신고 위치가 활주로 축선과 인접해 있다
THEN 대형 수변종 착지 및 충돌 위험 = 높음
     → 4호탄 위심 타격을 통한 강력 경퇴
     → 해당 수로 또는 유도로를 '영구 배제 구역'으로 인식시키기
     → 타격 후 재진입 여부 30분 내 재점검
     → [[2026-03_L1_신고기록#CASE-2026-03-002]] 참고 (중백로 타격 성공 사례)
```

**근거 사건**:
- [[2026-03_L1_신고기록#CASE-2026-03-002]] (중백로 1마리, AS-34 유도로, 4호탄 2발)

**봄철 특징**: 산란기 진입으로 대형 수변종의 영토 의식 강화. 공포탄만으로는 퇴치 불충분. **4호탄 타격으로 물리적 배제 필수**.

---

### B-02. 오리류 재진입 봄철 신호 🟡

```
IF  신고 종이 오리류(흰뺨검둥오리 등)다
AND 신고 위치가 유수지다
AND 개체 수가 5마리 이상이다
AND 시간대가 오후(14:00~18:00)이다
THEN 봄철 오리류 복귀 패턴 = 확인
     → 공포탄 + 4호탄 복합 사격 (신뢰도 높이기)
     → 동측 해안가 등 공항 외부로 유도
     → 해당 유수지 48시간 집중 점검 강화
     → [[2026-03_L1_신고기록#CASE-2026-03-005]] 참고 (오리 8마리 복합 사격)
```

**근거 사건**:
- [[2026-03_L1_신고기록#CASE-2026-03-005]] (오리 8마리, 유수지, 복합 사격)

**해석**: 2월 해동기 오리류에서 3월 봄철 복귀 패턴으로 진화. 4월 산란기 대비 신호.

## 트리거 C — 번식기 및 민원 관리

---

### C-01. 까마귀 대규모 결집 + 민간 민원 🟠

```
IF  신고 처가 민간(거주민) 또는 외부 기관이다
AND 신고 종이 까마귀다
AND 신고 위치가 랜드사이드 스테이징 구역이다
AND 개체 수가 20마리 이상이다
THEN 에어사이드 진입 차단 + 민원 관리 = 우선순위 높음
     → 현장 트랩(Trap) 추가 배치
     → 1~2개체 상징적 포획으로 군집 심리 제압
     → 유인 먹이원 제거 (쓰레기 정비)
     → 에어사이드 진입 경로에 공포탄 소음 벽 형성
     → 거주민과의 협력 채널 유지 및 주기적 업데이트
     → [[2026-03_L1_신고기록#CASE-2026-03-004]] 참고 (까마귀 20마리 포획 성공 사례)
```

**근거 사건**:
- [[2026-03_L1_신고기록#CASE-2026-03-004]] (까마귀 20마리, 1개체 포획)

**중요성**: **민간 신고자의 신뢰도 유지**가 외곽 예찰망의 핵심. 포획 성공으로 시민 신뢰 확보.

---

### C-02. 랜드사이드 까치/비둘기 둥지 시도 — 4월 대비 🔴

```
IF  신고 유형이 둥지 시도다
AND 신고 종이 까치 또는 비둘기다
THEN 번식기 본격 진입 신호 = 4월 대비 필수
     → 발견 즉시 물리적 제거
     → 차단재 강화 살포
     → 해당 시설물을 "일일 2회 점검 리스트"에 등록
     → 둥지 제거 후 전후 사진 기록 (경향 추적)
     → 3월에 1건 → 4월에는 10건 이상 예상
```

**비고**: 3월 직접 신고 없음. 2월 [[2026-02_L1_신고기록#CASE-2026-02-003]] 참고. 4월 대비 사전 경계.

## 트리거 D — Q1 누적 평가 및 Q2 대비

---

### D-01. Q1(1월~3월) 종합 평가

```
IF  Q1 데이터 분석이 완료되었다 (누적 15건)
THEN 다음을 종합 평가한다

【신고 추이】
- 1월: 13건 (기러기 대규모, 말단 집중)
- 2월: 5건 (해동기, 수역 진입)
- 3월: 5건 (번식기, 다종 다양화)
- 총 23건 (변화: 대규모 → 소규모 → 다양화)

【위협 진화】
- 1월: 대규모 군집(300마리) → 2월: 중규모(15마리) → 3월: 다종 분산(10+5+3+20+8마리)
- 1월: 활주로 말단 → 2월: 수역 → 3월: 활주로 중앙 + 주기장 침입
- 신고 건수는 감소하나, 위협 지점은 분산 및 심화

【예방 성과】
- 신고 23건 모두 즉각 대응 (성공률 100%)
- 대응 시간 평균 14.5분 (목표 15분 이내 달성)
- 신고 채널 다각화 성공 (5개 채널 활성)

【4월 전략】
- 소형종 활주로 기착 계속 증가 → FOD 점검 주기 단축
- 대형 수변종 활주로 주변 진입 → 4호탄 타격 빈도 증가
- 번식기 둥지 설치 다발화 → 선제적 물리적 제거
- 민간 협력 확대 → 거주민 신고 채널 활성화
```

## 베테랑의 한마디

"3월의 데이터는 **에너지가 넘칩니다**. 신고 한 건 한 건이 공항의 안전과 직계되어 있습니다.

**'신고는 결과가 아니라 기회'**입니다. 신고를 받은 시점이 **가장 빠른 대응 시점**이 되어야 하며, 대응 후에는 그 조류가 **왜 그곳을 선택했는지에 대한 생태적 답**을 찾아야만 4월의 더 큰 도전을 막아낼 수 있습니다.

18년의 경력은 기술이 아니라, **집요한 '왜'라는 질문**에서 완성됩니다.

**'신고는 자산입니다.'** 
매달 5~13건의 신고가 들어올 때마다, 그것은 우리가 공항을 지키고 있다는 증거입니다. 4월의 산란기를 맞이하기 전에, 1월의 데이터·2월의 신호·3월의 신뢰를 가지고 최고의 준비를 하시기 바랍니다."
