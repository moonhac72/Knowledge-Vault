## 【파일 용도별 사용 가이드】

### 【L1 - 신고 기록】
**"누가, 언제, 어디서, 뭘 신고했어?"** 질문에 답함

```
예시:
- "1월에 조류충돌이 몇 건?"     → L1 신고유형별 분포
- "CASE-011은 뭐였어?"          → L1 CASE-2026-01-011 확인
- "3월에 중백로 신고가 있었어?" → L1 CASE-2026-03-002 확인
```

### 【L2 - 패턴 분석】
**"왜 그런 신고가 나왔을까?"** 통계·추이 분석

```
예시:
- "1월 특이점은?"              → L2 위협 우선순위, 월간 이슈
- "어느 지점이 가장 위험해?"   → L2 장소별 분포, 반복 출현 위치
- "종별 변화는?"              → L2 조류종별 분포, 월별 특징
- "신고 채널이 왜 달라졌어?"  → L2 신고자 분포 (1월 1개 → 2월 5개)
```

### 【L3 - 판단 트리거】
**"지금 뭘 해야 해?"** 현장 즉시 판단 규칙

```
예시:
- "강풍 + 13물인데?"           → L3 B-01 대조기 경보
- "활주로 중앙에 종다리 10마리" → L3 A-01 최고 경보 (공포탄 10발)
- "기장이 기러기 300마리 신고했어" → L3 D-01 RED ALERT
```
