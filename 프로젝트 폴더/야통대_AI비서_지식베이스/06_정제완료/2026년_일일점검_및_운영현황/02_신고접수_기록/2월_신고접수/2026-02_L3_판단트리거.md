# 2026-02 L3 판단 트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-02_L2_패턴분석]]
> **원본 데이터**: [[2026-02_L1_신고기록]]
> **적용 범위**: 2월 데이터 기반 (표본 5건)
> **신뢰도 단계**: △ 제한적 (2월·3월 누적 데이터 추가 필요)

---

## 사용 방법 (현장 배포용)

**지금 이 상황인데 뭘 해야 해?**
1. 현재 상황의 장소·종·신고처를 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행

## 트리거 A — 수역 조류 신고 기반

---

### A-01. 배수로/유수지 오리류 10마리 이상 군집 🔴

```
IF  신고 위치가 배수로 또는 유수지다
AND 신고 종이 오리류(흰뺨검둥오리, 청둥오리 등)다
AND 개체 수가 10마리 이상이다
THEN 다중 충돌 위험 = 높음
     → 즉시 4호탄(위심 사격) 투사
     → 개체 분산 완료 후 해당 수역 30분 재점검
     → [[2026-02_L1_신고기록#CASE-2026-02-002]] 참고 (15마리 성공 사례)
```

**근거 사건**:
- [[2026-02_L1_신고기록#CASE-2026-02-002]] (오리 15마리, 위심 사격 성공)

**왜 이게 위험한가**: 오리 15마리가 동시에 엔진에 흡입될 경우 다중 충돌(Multiple Strike) 발생 가능.

---

### A-02. 왜가리/백로 등 대형 수변종 출현 🟡

```
IF  신고 종이 왜가리 또는 백로류다
AND 신고 위치가 배수로·유수지·활주로 주변이다
THEN 대형 충돌·착지 위험 = 중간 수준
     → 공포탄(Flare) 사격으로 순간 퇴치
     → 개체 이동 경로 추적 (수로 따라 다른 지점으로 이동 가능)
     → [[2026-02_L1_신고기록#CASE-2026-02-001]] 참고 (왜가리 단일 개체 사례)
```

**근거 사건**:
- [[2026-02_L1_신고기록#CASE-2026-02-001]] (왜가리 1마리, 공포탄 5발 사격)

**대응 포인트**: 왜가리는 높은 수심을 선호하므로 배수로 따라 이동. 한 지점에서만 대응하면 이웃 지점으로 재진입.

---

### A-03. 청둥오리 등 중형 오리류 5마리 이상 🟡

```
IF  신고 종이 청둥오리다
AND 개체 수가 5마리 이상이다
AND 신고 위치가 유수지다
THEN 해동기 오리류 집결 신호 = 확인
     → 폭죽(Fireworks) + 경보음 동시 가동
     → 이탈 확인 후 배수로/유도로 점검 강화
     → [[2026-02_L1_신고기록#CASE-2026-02-005]] 참고 (동측 해안가로 이탈 성공 사례)
```

**근거 사건**:
- [[2026-02_L1_신고기록#CASE-2026-02-005]] (청둥오리 5마리, 폭죽 사격)

**해동기 특징**: 얼었던 유수지가 녹으면서 오리류가 집결. 이 시기 적극 퇴치하면 공항 내 서식 억제 가능.

## 트리거 B — 번식기 선제 신호

---

### B-01. 까치/비둘기 둥지 시도 신고 🔴

```
IF  신고 유형이 둥지 시도다
AND 신고 종이 까치 또는 비둘기다
AND 신고 위치가 랜드사이드 조명탑 또는 시설물이다
THEN 번식기 선제 대응 = 우선순위 최고
     → 인력을 투입한 물리적 제거 (즉시)
     → 제거 후 해당 시설물에 조류 기피 케미컬 살포
     → 해당 지점을 주간 2회 이상 정기 순찰 리스트 등록
     → [[2026-02_L1_신고기록#CASE-2026-02-003]] 참고 (게이트 까치 둥지 성공 제거 사례)
```

**근거 사건**:
- [[2026-02_L1_신고기록#CASE-2026-02-003]] (까치 2마리 둥지, 물리적 제거 완료)

**중요성**: 2월 한 건의 둥지 시도가 3월에는 10건 이상으로 증가할 수 있음. 선제 차단 필수.

---

### B-02. 랜드사이드 까마귀 대규모 결집 신고 🟠

```
IF  신고 처가 외부 기관(민가/거주민) 또는 보안대다
AND 신고 종이 까마귀다
AND 신고 위치가 랜드사이드 스테이징(Staging) 구역이다
AND 개체 수가 10마리 이상이다
THEN 에어사이드 진입 차단 = 우선순위 높음
     → 현장 트랩(Trap) 추가 배치
     → 유인 먹이원 제거 (쓰레기 정비)
     → 에어사이드 진입 경로에 공포탄 소음 벽 형성
     → 민간 신고자와 협력 채널 유지
```

**비고**: 2월에는 직접 신고 없음. 3월 예측 트리거로 미리 등록.

## 트리거 C — 기장 신고 및 예찰망 강화

---

### C-01. 항공기 기장(Pilot) 맹금류 신고 🔴

```
IF  신고자가 항공기 기장이다
AND 신고 종이 맹금류(황조롱이 등)다
AND 신고 위치가 활주로 상공 또는 고도 500ft 이상이다
THEN 예찰망 사각지대 확인 = 중요 신호
     → 즉각적인 예찰 차량 출동
     → 해당 활주로 섹터 순찰 강화
     → 인근 조명탑 및 ILS(기동지역) 상단부 정밀 수색
     → 기장 신고 후 대응 시간 10분 이내 달성
     → [[2026-02_L1_신고기록#CASE-2026-02-004]] 참고 (기장 신고 사례)
```

**근거 사건**:
- [[2026-02_L1_신고기록#CASE-2026-02-004]] (기장 신고, 황조롱이 고공 관찰)

**중요성**: 기장 신고는 **조류탐지레이더 도입 필요성**을 시사. 지상 예찰만으로는 한계 있음.

---

### C-02. 다채널 신고처 활성화 🟢

```
IF  신고 채널이 다각화되었다
    (관측탑/기장/보안/유지보수/조류관리소 모두 신고)
THEN 예찰 체계 = 균형잡힘으로 판단
     → 각 신고처별 대응 매뉴얼 정비
     → 월 1회 신고처 협력 미팅 개최
     → 신고 접수 → 출동 → 조치 시간 기록 (Best Practice 공유)
```

**2월 성과**: 5개 신고처가 균등하게 신고 → 협력 체계 성공 신호.

---

## 트리거 D — 월간 통합 평가

---

### D-01. 2월 종합 평가 및 3월 대비

```
IF  2월 신고 분석이 완료되었다
THEN 다음을 확인한다

【성과】
- 신고 5건 모두 조치 성공 (성공률 100%)
- 신고 채널 다각화 (5개 채널)
- 대응 시간 평균 16분 (양호)

【과제】
- 신고 건수 감소 (1월 13건 → 2월 5건)
  → 겨울철 종료 신호이나, 신고 누락 가능성 확인 필요
- 기장 신고 대응 시간 짧음 (10분)
  → 고공 위협 탐지 도구(레이더) 도입 시급
- 3월 준비: 둥지 시도 증가 예상 → 선제 예찰 강화

【3월 전략】
- 소형종(종다리) 활주로 진입 대비
- 번식기 둥지 시도 다발 예상
- 대형 수변종(왜가리) 활주로 주변 증가 예상
```
