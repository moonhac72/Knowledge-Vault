# 2026-04 사체수거 L3 판단트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-04_사체수거_L2_패턴분석]]
> **원본 데이터**: [[2026-04_사체수거_L1_기록]]
> **적용 범위**: 4월 데이터 기반 (표본 13개체)
> **신뢰도 단계**: ★★★★ (높음)

---

## 사용 방법 (현장 배포용)

**사체를 발견했는데 뭘 해야 해?**
1. 사체의 상태·위치·종을 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행
4. WHY → 판단 근거 이해

---

## 트리거 A — 항공기 중대 충격 (LG 끼임 및 대형종)

---

### A-01. 랜딩기어(LG) 부위 사체 발견 시 🚨 (최고 경보)

```
IF  사체가 항공기 랜딩기어에 고착되어 있거나 낙하했다
AND 조류 종이 말똥가리·왜가리 등 대형종이다
THEN 즉시 해당 항공기 편명 및 도착/출발 시각 확인
     → 정비팀에 기체 하부(유압 라인, 센서) 정밀 점검 요청
     → 해당 항공기의 이전 비행 경로(Staging Area) 예찰 강화
     → [[2026-04_사체수거_L1_기록#CASE-2026-04-017]] 참고
```

**WHY**: 랜딩기어 끼임은 단순 충돌을 넘어 기체 손상(유압계통 파손)으로 이어질 수 있는 **치명적 위협**임.

---

## 트리거 B — 항공기 후류 및 지열 트랩 (양호 상태)

---

### B-01. 포장면 '양호' 상태 소형종 발견 시 🔴

```
IF  사체가 활주로/유도로 포장면에서 발견됐다
AND 사체 상태가 외상 없이 '양호'하다
AND 날씨가 맑고 일교차가 큰 오전 시간대다
THEN 항공기 후류(Wake Turbulence) 피해로 판단
     → 즉시 해당 구역 포장면 이물질(FOD) 수거
     → 인근 초지/배수로에 대기 중인 소형종(물떼새) 즉시 경퇴
     → [[2026-04_사체수거_L2_패턴분석#지열트랩현상]] 참고
```

**WHY**: 맑은 날 오전에 포장면에서 발견되는 양호한 사체는 지열을 찾아 기착했다가 후류에 의한 **'내장 파열/뇌진탕'**으로 즉사한 경우임.

---

## 트리거 C — 포유류 침입 보안 (고라니)

---

### C-01. 에어사이드 내측 고라니 사체 발견 시 🚨 (최고 경보)

```
IF  포유류 사체(고라니 등)가 외곽도로가 아닌 '내측 녹지대/주기장'에서 발견됐다
THEN 즉시 아래를 실행한다
     
1. 반경 500m 내 보안 펜스 하단 굴착 흔적 전수 조사
2. 침입 지점으로 의심되는 배수로 게이트 차단막 상태 확인
3. 기동지역 내 생존 개체 존재 가능성 염두에 둔 야간 열화상 수색 실시
4. [[2026-04_사체수거_L1_기록#CASE-2026-04-002]] 참고
```

**WHY**: 포유류의 내측 진입은 항공기 조향 및 엔진 흡입 시 **치명적 사고(Catastrophic Incident)**를 유발하는 중대 보안 결함임.

---

## 트리거 D — 이동기 지빠귀류 집중 관리

---

### D-01. 지빠귀류(되지빠귀 등) 연쇄 발견 시 🟡

```
IF  24시간 내 동일 구역에서 지빠귀류 사체가 2개 이상 발견됐다
THEN 해당 구역을 '이동기 집중 횡단 경로'로 지정
     → 일몰/일출 전후 해당 구간 순찰 빈도 2배 상향
     → 이동기 임시 경퇴팀 배치 검토
```
