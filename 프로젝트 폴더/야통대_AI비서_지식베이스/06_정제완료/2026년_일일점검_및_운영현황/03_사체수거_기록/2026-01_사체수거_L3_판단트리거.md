# 2026-01 사체수거 L3 판단트리거 — IF-THEN 규칙
> **계층**: L3 (판단 트리거 / 현장 즉시 판단용)
> **이전 계층**: [[2026-01_사체수거_L2_패턴분석]]
> **원본 데이터**: [[2026-01_사체수거_L1_기록]]
> **적용 범위**: 1월 데이터 기반 (표본 11개체)
> **신뢰도 단계**: △ 제한적 (2월·3월 데이터 추가 필요)

---

## 사용 방법 (현장 배포용)

**사체를 발견했는데 뭘 해야 해?**
1. 사체의 상태·위치·종을 먼저 확인
2. 아래 트리거 A/B/C 중 일치하는 것 찾기
3. THEN → 즉시 실행
4. WHY → 판단 근거 이해 (선택사항)

---

## 트리거 A — 항공기 관련 사체 (완파/후류 피해)

---

### A-01. 활주로 포장면 완파 사체 발견 🚨 (최고 경보)

```
IF  사체가 활주로 포장면에서 발견됐다
AND 사체 상태가 '완파'(Destroyed) 또는 '반파'다
AND 조류 종이 종다리·수변종이다
THEN 항공기 후류 피해 확정 = 즉시 보고
     → 해당 활주로 구간 위협도 '높음'으로 격상
     → 동일 기상 조건 시 집중 순찰 강화
     → [[2026-01_사체수거_L1_기록#CASE-2026-01-006]] 참고 (강설+북풍 패턴)
```

**근거 사건**:
- [[2026-01_사체수거_L1_기록#CASE-2026-01-006]] (종다리 2개 완파, 3R/W 남측 V 유도로)

**현장 판단 체크리스트**:
- ✅ 사체가 포장면 상에 있나? (유도로 포함)
- ✅ 신체가 심하게 파괴되었나? (깃털 산란, 내장 노출)
- ✅ 발견 위치가 활주로축선 또는 이착륙 경로와 일치하나?

**WHY**: 항공기 후류 피해는 저고도에서의 고에너지 충격이므로 신체 파괴가 심함. 이는 미래 충돌 사고를 예고하는 **직접적인 항공기 관련 위협**.

---

### A-02. 항공기 후류 피해 패턴 인식 🔴

```
IF  강설(눈) 이후 북풍이 불고 있다
AND 기온이 -5℃~0℃ 범위다
AND 종다리 사체가 발견됐다
THEN 이 조건 조합 = 항공기 후류 위험의 '골든타임'
     → 3활주로 남측 V 유도로 집중 순찰 개시
     → 포장면 세척 또는 곤충 제거 우선순위 상향
     → [[2026-01_사체수거_L2_패턴분석#강설북풍조건]] 참고
```

**패턴 인식**:
1. **강설** → 지표면 씨앗 노출
2. **북풍** → 종다리가 바람을 등지고 남측(따뜻한 곳) 유도로로 집중
3. **-5℃~0℃** → 조류의 신진대사 활발해지면서 먹이 활동 증가
4. **결과** → 활주로 포장면에서의 비상(Fly-up) → 이륙 항공기 후류 직격

**WHY**: 1월 29일 패턴이 **반복 가능한 특정 기상 조건**임이 확인됨. 이 조건이 2월, 3월에도 재발할 것으로 예상.

---

## 트리거 B — 동절기 자연사 (양호 상태)

---

### B-01. 극한 저온(-10℃ 이하) 동사 신호 🟡

```
IF  기온이 -10℃ 이하다
AND 북서풍 강풍(6m/s 이상)이 지속된다
AND 수조류(물닭, 오리류) 사체가 발견됐다
THEN 동사(凍死) 추정 = 위협도 '중간'으로 판단
     → 해당 구역 수역 조류 개체수 증가 모니터링
     → 배수로·유수지 집중 순찰 실시
     → [[2026-01_사체수거_L1_기록#CASE-2026-01-002]] 참고 (01-02 3종 동시)
```

**근거 사건**:
- [[2026-01_사체수거_L1_기록#CASE-2026-01-002]] (물닭, 중대백로, 뿔논병아리)

**WHY**: 극한 동절기에 양호 상태 사체는 **자연사** 가능성이 높음. 그러나 발견 위치가 활주로 포장면이면 항공기 후류 가능성도 교차 검증해야 함.

---

### B-02. 수조류 반복 출현 구역 표시 🟡

```
IF  같은 위치에서 물닭·흰뺨검둥오리 등 수조류 사체가 반복 발견됐다
THEN 해당 위치를 '반복 출현 구역' 리스트에 등록
     → R11~R12 RB (물닭, 중대백로)
     → 307번~349번 주기장 인근 (물닭 반복 3회)
     → 대조기(13물↑) 또는 강풍 조건 시 우선 점검
```

**발견 위치들**:
- R11~R12 RB
- 307번 주기장
- 327번 주기장  
- 349번 주기장

**WHY**: 주기장 주변 배수로는 수조류의 먹이(어류, 수생곤충)가 풍부한 지점. 이 구역에 수조류가 정착하면 포식자 또한 따라온다.

## 트리거 C — 포식 활동 및 침입 신호

---

### C-01. 주기장 인근 취식흔 발견 → 맹금류 거점 신호 🔴

```
IF  주기장(307번, 327번) 주변에서 취식흔 사체가 발견됐다
THEN 해당 주기장을 '맹금류 급식 거점'으로 지정
     → 야간 예찰팀 경계 강화
     → 취식흔 발견 후 48시간 내 추가 사체 여부 확인
     → 맹금류 서식 흔적(배설물, 깃털) 수집
     → [[2026-01_사체수거_L1_기록#CASE-2026-01-002]] 뿔논병아리 취식흔 참고
```

**근거 사건**:
- [[2026-01_사체수거_L1_기록#CASE-2026-01-002]] (307번 주기장 뿔논병아리 취식흔)
- [[2026-01_사체수거_L1_기록#CASE-2026-01-003]] (327번 주기장 물닭 취식흔)

**WHY**: 맹금류가 주기장을 사냥터로 선택했다는 뜻. 소형 맹금류는 간접 퇴치 효과가 있으나, 대형 맹금류가 정착하면 기동지역 내 활동 가능성 증대.

---

### C-02. 포유류(고라니) 사체 발견 → 울타리 침입 경로 신호 🔴

```
IF  포유류 사체(고라니)가 기동지역 경계 지점(G4초소 외곽도로)에서 발견됐다
THEN 즉시 아래를 실행한다

1. 사체 발견 위치 반경 100m 울타리 훼손 여부 육안 점검
2. 침입 경로 사진 기록 (향후 보수 참고자료)
3. 기동지역 내 추가 개체 침입 여부 수색
4. 시설팀에 울타리 보수 요청 + 우선순위 상향
   → [[2026-01_사체수거_L1_기록#CASE-2026-01-003]] 참고 (G4초소 사례)
```

**근거 사건**:
- [[2026-01_사체수거_L1_기록#CASE-2026-01-003]] (고라니 1개체, G4초소 외곽도로)

**포유류 침입의 연쇄 위험**:
- 1월: 고라니 1개체 침입 신호
- 2월: 같은 경로로 추가 개체 침입 가능성 증대
- 3월: 더 큰 포유류(멧돼지 등) 침입 가능성

**WHY**: 포유류는 조류와 달리 체구가 크고 이동 속도가 느려, **활주로 진입 시 항공기와의 충돌로 대형 피해 발생 가능**.

## 트리거 D — 조석(물때)과 수위 변화

---

### D-01. 대조기(13물↑) 고조 조건 → 수조류 유입 증가 🟡

```
IF  조석이 13물 이상(대조기)다
AND 배수로/유수지 수위가 상승했다
THEN 수조류(오리류, 물닭) 기동지역 배수로 유입 증가
     → 배수로 주변 집중 점검
     → 대조기 + 강풍 조합 시 우선순위 '높음'
     → [[2026-01_사체수거_L1_기록#CASE-2026-01-004]] 참고 (01-26 15물)
```

**근거 사건**:
- [[2026-01_사체수거_L1_기록#CASE-2026-01-004]] (흰뺨검둥오리, 01-26 15물 대조기)

**WHY**: 만조 시 해수 수위 상승 → 주변 배수로로 물 역류 → 수조류가 담수 배수로를 선호하면서 기동지역으로 유입.

---

```
IF  1월 사체수거 데이터 분석이 완료되었다
THEN 다음을 종합 평가한다

【최고 위협 신호】
- 항공기 후류 피해 (종다리 2개 완파) → 1순위
- 포유류 울타리 침입 (고라니 1개) → 2순위  
- 수조류 집중 발생 (01-02 3종) → 3순위

【2월 선제 대응】
1. 강설+북풍 조건 시 3R/W 남측 V 유도로 우선 순찰
2. 수조류 반복 구역(307~349번 주기장) 중점 관리
3. G4초소 울타리 보수 + 침입 경로 모니터링
4. 맹금류 서식 추적 (307, 327번 주기장)

【신뢰도】
- △ 제한적 (11개체 표본)
- 2·3월 데이터 추가 후 신뢰도 ▲로 상향 예정
```
