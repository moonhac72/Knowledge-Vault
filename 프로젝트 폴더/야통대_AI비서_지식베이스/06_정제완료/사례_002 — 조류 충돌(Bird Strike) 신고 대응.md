
# 사례_002 — 조류 충돌(Bird Strike) 신고 대응

## IF-THEN 판단 로직

### 1단계 — 신고 접수 전화에서 확보할 정보 (우선순위 순)

IF 조류 충돌 신고 전화를 받았다
THEN 아래 순서대로 즉시 질문한다

1. "이륙 중 충돌입니까, 착륙 중 충돌입니까?"
   - IF 이륙 중 → 중요도 낮음. 현장 사진 확보 + 신고대장 기록으로 종결
   - IF 착륙 중 → 2번으로 진행

2. "기장이 충돌을 인지했습니까?"
   - IF 기장 미인지(정비사만 발견) → 중요도 낮음. 단체 카톡 보고 + 보고서 작성으로 종결
   - IF 기장 인지 → 3번으로 진행 (중요도 높음)

3. "충돌 고도(ft)를 알 수 있습니까?"
   - IF 200ft 이하 → ON AIR 상황. SNS 정식 보고 문자 발송 + 보고서 작성
   - IF 200ft 초과 → Near Off 상황. 보고서 작성
   - IF 고도 모름 → 현장에서 기장보고서 로그 직접 확인 또는 기장과 직접 통화

4. "항공기 손상 여부를 알 수 있습니까?"
   - IF 손상 확인 → 중요도 최고. 경계/심각 단계 구분 후 통제 강화
   - IF 손상 불명확 → 현장 출동 후 정비사와 함께 확인

WHY: 인천공항 기준 ON AIR(착륙 200ft 이내, 이륙 500ft 이내)와
Near Off를 구분하며, 이에 따라 보고 체계와 통제 강화 수위가 달라진다.

---

### 2단계 — 현장 도착 후 판단

IF 현장에서 충돌 흔적을 확인했다
THEN 아래를 순서대로 실시한다

- 혈흔 응고 상태 확인
  WHY: 응고 상태로 충돌 경과 시간을 추정할 수 있다.
  현지 이륙 충돌 여부를 교차 검증하는 근거가 된다.

- 깃털 + 혈흔 채취
  WHY: 국립생물자원관 DNA 분석 의뢰 → 충돌 조류 종 확인 가능

- 충돌 고도 + 터치다운 시간으로 충돌 지점 추정
  WHY: 터치다운 시간과 충돌 고도를 알면 충돌 발생 시간대와
  공항 주변 충돌 지점을 역산할 수 있다.

- 사진 촬영 + 보고서 작성

---

## 위협 우선순위

- 1순위: 항공기 손상 여부 (운항 가능/불가 판단)
- 2순위: 기장 인지 + 충돌 고도 (ON AIR / Near Off 판단)
- 3순위: 이륙/착륙 구분, 기장/정비사 인지 구분

---

## 핵심 수치 기준 (인천국제공항)

- ON AIR 기준: 착륙 200ft 이내 / 이륙 500ft 이내
- ON AIR → SNS 정식 보고 문자 + 보고서 작성
- Near Off → 보고서 작성
- 항공기 손상 → 경계/심각 단계 격상 + 통제 강화
