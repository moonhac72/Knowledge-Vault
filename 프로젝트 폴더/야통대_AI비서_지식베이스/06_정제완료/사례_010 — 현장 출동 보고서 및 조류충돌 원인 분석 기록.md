## IF-THEN 추후 보강 판단

IF 금일 조류충돌 건의 조류 종이 미확인이다
THEN 아래 두 가지를 병행 진행한다

1. 혈흔·조직·깃털 → 국립생물자원관 DNA 분석 의뢰
   → 결과 나오면 보고서에 대조 기록

2. 이전 조류충돌 자료 검색
   → 기장 인지 / Near Off 처리 / 정확한 고도(ft) 확인
   → 금일 건과 동일 패턴 자료 확인

WHY: 두 가지 근거가 쌓이면 동일 구역·동일 시간대
조류충돌 예상 및 선제 대비책 수립이 가능하다.

## 위협 우선순위

- 1순위: DNA 분석 의뢰 → 충돌 조류 종 확인
- 2순위: 과거 동일 패턴 자료 대조 → 반복 충돌 여부 확인
- 3순위: 충돌 추정 시간대·구역 집중 순찰 일정 반영
