# 🎯 이창환의 목표와 방향

## 단기 목표 (1~6개월)

### 야통대 전문자료 구축
- 옵시디언 야통대 폴더 월별 자료 업로드
- 일일점검일지, 신고접수, 사체수거 데이터 체계화
- 조류충돌 DNA 분석 결과 데이터베이스 구축

### 지식창고72 완성
- 텔레그램 봇 기사 분석 + 데일리 노트 자동화
- AI 비서가 과거 기록을 참조해서 현명한 조언을 주는 시스템

### 건강 습관 개선
- 커피 믹스 2잔 이하, 알코올 줄이기
- 마음의 여유 회복

## 중기 목표 (6개월~2년)

### 야통대 무인 시스템 아이디어 구체화
농슬라 7cm 정밀 자율주행 플랫폼을 야통대 차량에 접목.
활주로 주변 무인 패트롤 로봇 순찰 시스템.

### 야통대 전문 보고서 작성
18년 경력 + 축적된 데이터 → 전문자료 발간

### AI 로컬 인프라 완성
Mac Mini + Ollama + LiteLLM + 텔레그램 봇 최적화

## 장기 목표 (은퇴 후)

### 은퇴 후 전문가로서 새로운 시작
18년 야통대 경력 + 지식창고 = 은퇴 후 새로운 가치 창출의 기반

### 지식의 사회적 환원
축적한 전문지식과 인사이트를 사회에 기여하는 방식 모색
