# 📋 NPU 노트북 천재적 활용법

## 1. Local Whisper 음성 비서화
- OpenAI Whisper 모델을 로컬에 설치
- 유튜브 뉴스/팟캐스트를 NPU가 실시간 텍스트 변환
- AI가 즉시 요약 → 옵시디언에 자동 저장
- 손 하나 안 대고 지식 베이스 구축

## 2. 개인용 지식 그래프 분석
- 옵시디언 노트 1,000개 중 서로 관련 있지만 미연결된 노트 쌍 발굴
- 인간의 뇌가 놓친 창의적 연결고리를 AI가 찾아냄
- 새로운 논문/기획안 소재 발굴에 활용

## 3. 로컬 코딩 비서 (Continue.dev)
- 코딩 몰라도 파이썬 스크립트 작성 가능
- 노트북 내 로컬 AI가 코드 작성 + 오류 수정
