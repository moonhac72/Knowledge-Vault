# 📋 선택 1로 설정 완료

선택 1로 설정을 완료함.

## 결정 근거

- 일단 경과를 지켜보고 이상 없을 시 그대로 계속 진행
- 이상 발생 시 선택 2로 변경 예정

## 이상 발생 기준

텔레그램 봇 ↔ 맥미니 Claude Code(터미널) 연동 불가 상태
- 외부에서 텔레그램으로 자료·정보를 전송 → 맥미니 옵시디언에 자동 저장하는 워크플로우가 중단될 경우
- 이 연동이 핵심 파이프라인이므로 불가 시 즉시 선택 2로 전환

## 선택 2 (대안)

핸드폰에 터미널 전용 앱 설치 → 맥미니와 동일한 환경 구현 → 직접 접근
- 명령어를 직접 입력해 연결 설정 가능
- 텔레그램 봇 우회, 직접 제어 방식
