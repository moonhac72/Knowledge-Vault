# 📋 외부에서 터미널 접속 불가 시 대응방안

## 상황

외부에 있을 때 `tmux attach -t telegram` 입력 불가 → 좀비 상태 수동 확인 불가.

## 선택 1 — 타이머를 짧게 줄이기 (간단)

지금 6시간 주기를 2시간으로 줄이면 좀비 상태 최대 대기가 2시간으로 단축됨.

`claude-telegram.sh` 수정:

```bash
perl -e 'alarm 7200; exec @ARGV' -- claude --channels plugin:telegram@claude-plugins-official
```

## 선택 2 — 아이폰에서 SSH 접속 (근본 해결)

Termius 앱(무료)으로 외부에서도 맥미니 터미널 사용 가능.

- 앱스토어 → Termius 설치
- 맥미니 IP 등록
- 어디서든 `tmux attach -t telegram` 가능

맥미니 SSH 활성화: 시스템 설정 → 일반 → 공유 → 원격 로그인 켜기
