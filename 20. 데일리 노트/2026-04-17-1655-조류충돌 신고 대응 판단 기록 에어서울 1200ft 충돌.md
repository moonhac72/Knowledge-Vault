# 📥 조류충돌 신고 대응 판단 기록 — 에어서울 1,200ft 충돌

---

## 상황 개요

| 항목 | 내용 |
|------|------|
| 항공편 | 에어서울 (도쿄 나리타 → 인천) |
| 터치다운 시간 | 15:31 |
| 신고 접수 시간 | 15:51 (터치다운 20분 후) |
| 충돌 인지 | 기장 인지 |
| 충돌 고도 | 1,200ft |
| 추정 충돌 시간 | 15:20~15:25 |
| 충돌 시점 | 착륙 접근 중 |

**신고 경로**: 기장 → 정비사 → 야통대

---

## 핵심 판단 프레임: ON AIR vs Near Off 구분

| 구분 | 기준 | 해당 사례 |
|------|------|-----------|
| **ON AIR** | 착륙 200ft 이내 / 이륙 500ft 이내 | 해당 없음 (1,200ft) |
| **Near Off** | 위 기준 외 | ✅ 해당 |

→ 1,200ft 충돌 = **Near Off** → SNS 정식 보고 문자 발송 불필요, 보고서 작성만

## 첫 번째 통화 — 우선순위별 정보 확보 (IF-THEN 판단)

정비사와의 **첫 통화**가 핵심. 중요도 순으로 질문하여 대응 전략을 즉시 결정한다.

| 순위 | 질문 | 답변 | 중요도 | 대응 |
|------|------|------|--------|------|
| 1 | 이륙 중 충돌? 착륙 중 충돌? | 착륙 시 충돌 | — | 본격 대응 개시 |
| 2 | 기장이 인지했나요? | 네 | 높음 | 충돌 고도 확보 필요 |
| 3 | 충돌 고도(ft) 아시나요? | 모름 | 높음 | 기장보고서 직접 확보 |
| 4 | 항공기 손상 유무? | 확답 불가 (추가 정비 필요) | 아주 높음 | 대부분 손상 없음으로 판단 |

**판단 결과**: 즉시 출동

---

## 대응 전략 — 중요도 분류

| 상황 | 중요도 | 처리 방법 |
|------|--------|-----------|
| 이륙 중 충돌 | 아주 낮음 | 충돌 부위 사진 + 신고접수대장 기록만 |
| 착륙 / 정비사 인지 | 낮음 | 단체 카톡 상황보고 + 보고서 작성 |
| 착륙 / 기장 인지 / 200ft 이내 (ON AIR) | 높음 | SNS 정식 보고 문자 + 보고서 |
| 착륙 / 기장 인지 / 200ft 초과 (Near Off) | 중간 | 보고서 작성 |
| 항공기 손상 | 아주 높음 | 경계/심각 단계 구분 → 통제 강화 |

## 1,200ft 고도 정보의 활용 가치

### ① 조류 종 특정
깃털·혈흔 채취 → 국립생물자원관 DNA 분석 의뢰 → 1,200ft에서 비행한 조류 종 확인

### ② 충돌 지점 역산
- 터치다운: 15:31
- 충돌 고도: 1,200ft
- 랜딩 방향 + 하강 속도 계산
- **추정 충돌 시간: 15:20~15:25**
- 추정 충돌 지점: 인천공항 접근 항로 특정 구간

### ③ 서식지·이동 패턴 데이터 축적
> "15:20~15:25, 1,200ft, 해당 조류가 해당 지점에 서식·이동 중"
> 이 데이터가 쌓일수록 조류충돌 예방 예측 모델의 핵심 입력값이 된다
