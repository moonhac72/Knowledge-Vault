/메모 명령으로 들어오는 내용은 `20. 데일리 노트/Daily Notes/YYYY-MM-DD.md` 데일리 노트에 저장한다.

**Why:** 처음에 00. Inbox에 저장했다가 사용자가 데일리 노트에 저장돼야 한다고 정정함.

**How to apply:**
1. 해당 날짜의 데일리 노트(YYYY-MM-DD.md)가 없으면 생성한다.
2. 메모 본문은 같은 폴더 내 별도 파일로 저장하고, 데일리 노트에 내부 링크([[파일명]])로 연결한다.
3. 데일리 노트 형식: `# YYYY-MM-DD Daily Note` → `## 기록` → `- [[파일명]] — 한줄 요약`
4. `/저장` 명령도 `/메모`와 동일하게 데일리 노트 폴더에 저장한다. (`/저장해줘`와 다름 — `/저장해줘`는 지식 창고 전체 분析 형식 적용)
