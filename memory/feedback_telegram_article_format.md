텔레그램으로 기사 분석 결과를 전송할 때는 단순 요약이 아닌, 아래 구조로 상세 내용을 직접 출력한다.

**왜:** 사용자가 텔레그램에서 요약만 보면 내용이 부실하다고 피드백함. 옵시디언 파일과 동일한 수준의 정보를 텔레그램에서도 바로 읽을 수 있어야 한다.

**How to apply:**
텔레그램 전송 형식은 다음 구조를 따른다:

```
✅ [카테고리] 저장 완료 (날짜 기준)
📁 [저장 경로 전체]
옵시디언에서 Pull하면 바로 확인 가능합니다.

---

📌 배경지식 및 요약
[기사 핵심 요약 + 배경지식 상세 설명 — 인물·기업·개념 풀어쓰기 포함]

---

📌 전문가적 분석 및 결론
[관련 전문가 의견 + 사회적 임팩트 + AI 컨설턴트 의견]
```

섹션 3-1 투자 시그널(경제 기사)은 핵심 판단 요약(D항)만 텔레그램에 포함하고, 전체 매트릭스는 파일에서 확인하도록 안내한다.
