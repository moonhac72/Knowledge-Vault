# 사용자 인터랙션 & 모델 선택 및 저장 워크플로우 지침

- **로컬 모델:** `gemma4:e4b` (`http://localhost:11434/v1` - Ollama API)
- **클라우드 모델:** `Gemini 3.7 Flash`

---

## 1. 상시 모델 선택 원칙 (Universal Model Selection)
- 아무리 간단한 단문 질문, 인사, 개념 문의, 개발, 기사 분석 등 **어떤 형태의 사용자 요청이든 예외 없이 항상 먼저 `ask_question` 선택 모달을 띄워** 모델을 선택받는다:
  > **질문:** "이번 질문/작업을 어떤 모델로 진행할까요?"
  > **선택지 1:** "로컬 모델(Gemma 4:e4b)로 진행해줘"
  > **선택지 2:** "클라우드 모델(Gemini 3.7 Flash)로 진행해줘"
- **로컬 모델(Gemma 4:e4b) 선택 시:** `http://localhost:11434/v1`로 프롬프트를 보내 로컬 모델의 순수 추론 결과로 응답/작업.
- **클라우드 모델(Gemini 3.7 Flash) 선택 시:** 클라우드 메인 모델이 직접 응답/작업 수행.

## 2. 문서화 및 옵시디언 지식 창고 저장 규칙 (`/저장해줘`)
- **저장 트리거:** 사용자가 요청문 말미에 **`/저장해줘`**를 명시한 경우에만 파일 저장 수행.
  - `10. 지식 창고` 하위 적정 카테고리(`10.1 경제`, `10.2 국제·지정학`, `10.3 테크·산업`, `10.4 사회·문화`, `10.5 환경·안전`) 또는 `20. 인사이트 융합` 폴더 내 해당 연월 폴더(예: `2026년8월/`)에 마크다운 파일로 저장.
- **일반 대화 및 단순 질문:** `/저장해줘` 문구가 **없는** 경우에는 파일을 생성하거나 덮어쓰지 않고, **채팅창에서만 답변**을 출력함.
